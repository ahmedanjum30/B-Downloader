Settings

General

Where downloads go and how BDownloader looks.

Download folder
Compressed, Documents, Music, Programs and Video folders inside it. A folder you pick for a download is used as it is.
Theme
When I close the window
In the tray, BDownloader still takes downloads from the browser and runs the queue's schedule.

Downloads

How each download uses your connection.

Connections per download
8
Each file downloads in parts over up to this many connections, adding them while the server keeps up. Sites that allow fewer get fewer.
Speed limitsFor all downloads together, torrents too: the gauge button in the top bar. For one download: its details (the i button).

Queue

Downloads saved for later, and when they run.

Downloads you add with Download later wait in the queue, under Queue in the sidebar.

Downloads at the same time
2
The queue starts the next download as each one finishes.
Schedule
Use 24-hour time, like 01:30

Torrents

Magnet links and .torrent files, and sharing them back.

Sharing (seeding)
Until they've uploaded times their size
Torrents download from other people, and work because people share back. Sharing as much as you downloaded (1) is the usual courtesy.
Opening torrentsMagnet links and .torrent files open in BDownloader from the browser extension, the Add download dialog, or Windows: choose BDownloader for them in Settings > Apps > Default apps.
Choosing filesA torrent's details (the i button) list its files. Tick or untick them at any time, also while it downloads.

Updates

How BDownloader stays up to date.

New versions
Automatic updates install while nothing is downloading and no dialog is open.
